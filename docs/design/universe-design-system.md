# BMSG UNIVERSE デザインシステム（新デザイン・モノトーン）

このファイルが統一の指標。画面を作る・直すときは、ここにある値と部品だけを使う。
数値の正本は `web/partials/UniverseTokens.html` の `:root` 変数（ここと一致させる）。

## 0. CSSの持ち方（いちばん大事な決まり）
見た目は部品ファイルにだけ書く。画面ごとのCSSは並べ方だけ。`npm test`（`tests/css-structure.test.mjs`）が毎回検査する。

| ファイル | 書くもの | 書かないもの |
| :- | :- | :- |
| `UniverseTokens.html` | 値（色・書体・文字の大きさ・角丸・高さ）。白い画面の値（`body.ui-light`）もここ | 部品 |
| `Styles.html` | 画面の枠：上のバー・下のメニュー・左のメニュー・検索・設定・通知の置き場所 | 画面ごとのもの |
| `UniverseTheme.html` | 部品：ボタン・戻る・入力欄・見出し・面・一覧・タブ・切り替え・写真・窓・読み込み中など（16章） | 画面の名前のついたクラス |
| 画面ごとのファイル（`KaraokeStyles.html` など） | 並べ方：display・grid・flex・gap・幅・高さ・余白・位置・重なり・動き | 色・背景・枠線・角丸・文字（書体・大きさ・太さ・字間）・影 |
| `<style data-content>` | 中身の見た目（トレカ・ポーカーのカードの絵柄、レア度の色、メンバーカラーの帯）。`CardStyles` `PokerStyles` `CoverStyles` だけ | ボタン・入力欄・戻る |

- 画面のHTMLには部品の名前をつける：`class="ui-btn ui-btn-solid karaoke-start"`。`karaoke-start` は並べ方（位置・幅）だけに使う。
- 見た目が足りないときは、画面のCSSではなく `UniverseTheme.html` に部品として足し、16章に書く。
- 色は直接書かない（`#fff` や `rgba()` は不可）。メンバーカラーのように色を渡すときは `--accent` に入れて、部品（`ui-accent-left` など）に使わせる。
- 色の種類は2つだけ：黒基調（`v2`）と白基調（`v2-light`：歌詞・カラオケ）。部品は同じで、トークンの値だけが変わる。
- 検査を手元で見る：`node scripts/css-rules.mjs`（ファイルごとの件数）／`node scripts/css-rules.mjs KaraokeStyles.html`（中身）。

## 1. 色
| 名前 | 値 | 使い道 |
| :- | :- | :- |
| 背景 | `#0e0e0e` | 画面全体 |
| 面（パネル） | `#181818` | タイル・一覧の行・カード |
| 面（押したとき・2段目） | `#1f1f1f` | ホバー・押下・アイコンの台 |
| 線 | `rgba(255,255,255,.12)` | 区切り・枠（普通） |
| 線（強い） | `rgba(255,255,255,.42)` | ボタンの枠・強調の枠 |
| 文字（本文・見出し） | `#ffffff` | 見出し・名前・ボタン |
| 文字（補足） | `rgba(255,255,255,.56)` | 説明・日付・ラベル |
| 選択中（白い塗り） | 背景 `#f2f2f2` / 文字 `#111` | 下のメニュー・メニューの選択中 |
| 危険（削除・不正解） | `#e5484d` | 削除ボタン・不正解・残りわずか |
| メンバーカラー | メンバーごとの色 | `--accent` で渡し、線・点・帯だけに使う |

色はこの表以外使わない。白・灰・黒だけ。白い画面（歌詞・カラオケ）は同じ名前のトークンが白基調の値に変わる。

## 2. 文字（フォント）
| 役割 | フォント | 例 |
| :- | :- | :- |
| 英字の大見出し（画面名・サイト名） | Inter 900 | DATA / LAB / BMSG UNIVERSE |
| 英字の小ラベル（見出しの上・番号） | Inter 800、大文字、字間 .2em | TODAY'S SONG / 01 |
| 日本語 | Noto Sans JP（700・500） | プロフィール / 歌詞 |
| 数字 | Inter 800 | 数値の大きな表示 |

## 3. 文字の大きさ（この段階だけ使う）
| 名前 | サイズ | 字間 | 使い道 |
| :- | :- | :- | :- |
| display | 56〜96px（画面幅に合わせる） | -.045em | DATA / LAB / HOME の大見出し |
| title | 22px | 0 | 曲名などの主役 |
| heading | 17px（太字） | .04em | タイル・行の名前 |
| body | 15px | .02em | 本文・ボタンの文字 |
| body-sm | 13px | 0 | 説明文 |
| label | 11px（大文字） | .2em | 小さなラベル・番号・ボタン内の英字 |

上の6種類以外のサイトは使わない。
日本語の見出し（画面名の下の小見出し）は 14px・字間 .22em。

## 4. 形と間隔
- 角丸：6px（全部これに統一）。例外は「枠のない画像」だけ。
- 間隔：4 / 8 / 12 / 16 / 20 / 24 / 32px のどれか。
- 画面の左右の余白：16px。

## 5. ボタン（3種類・高さは48px1つだけ）
| 種類 | 見た目 | 使い道 |
| :- | :- | :- |
| 枠（主） | 白い1pxの枠、文字白、透明 | 再生・保存・次へ |
| 白（強い） | 白い塗り、文字 `#111` | 下のメニューの選択中・決定のボタン |
| 削除 | 赤の枠（`--ui-danger`）、文字赤 | 削除だけ（`ui-btn-danger`） |

- 高さ 48px、左右の余白 24px、字間 .16em、文字 15px 太字。
- 押したとき：背景を `#1f1f1f` にする。アニメーションは 150ms まで。
- 無効：不透明度 .4。

## 6. タイル（データ・ラボ・ホームのカード）
- 面 `#181818`、1pxの線、角丸6px。
- 上：方眼の背景、ひし形の枠、2トーンのアイコン（四隅の照準枠つき）。
- 下：番号（label）、名前（heading）、説明（body-sm）。
- 押したとき：枠が強い線になり、面が少し明るくなる。

## 7. 一覧の行
- 高さ 60px 以上、面 `#181818`、区切りの線、右に「›」。

## 8. タブ・切り替え
- 外枠は細い線でつながった枠、選択中は塗る（`ui-tabs` + `ui-tab`）。
- 高さ 46px。

## 9. 上のバー・下のメニュー
- 上のバー：左にメニュー（☰）、真ん中にサイト名（英字・label）、右に検索。
- 下のメニュー：3項目（HOME・DATA・LAB）、アイコン＋英字（label）、選択中は白い塗り。

## 10. 通知・読み込み・エラー
- 通知：白い塗り、文字 `#111`、角丸6px、短く出て消える。
- 読み込み中：「読み込み中…」（日本語）。
- エラー：「エラー」（見出し）＋理由（body-sm）＋「もう一度読み込む」（枠のボタン）。

## 11. 文言
- 画面の名前・見出し・ボタンは日本語。英字は大見出しと小ラベルだけ。
- 「LOADING」「ERROR」「RETRY」などの英語の表示は使わない。

## 12. 作るときのチェック
- [ ] 色は1章の表だけ使っている
- [ ] 文字の大きさは3章の6種類だけ
- [ ] 字間は3章の値だけ
- [ ] ボタンは5章の3種類・高さ48px
- [ ] 角丸は6px、間隔は4の倍数
- [ ] 英語の表示は大見出しと小ラベルだけ

## 13. 戻る・タブ・読み込み・ポップアップ（分析で確定）
- 戻る：15章の `.ui-back`（枠なし・矢印と BACK・下に細い線）。
- タブ：ラベルは短く（トップ／メンバー／楽曲／時系列／その他）。幅は均等（flex 1 1 0）。
- 読み込み中：ホームと同じ面（`#181818` → `#1f1f1f`）の帯が流れる表示（スケルトン）。文字だけの「読み込み中」は使わない。
- ポップアップ：黒の半透明の背景、`#111` の面、1pxの線、見出しは日本語の見出しサイズ、閉じるは枠のボタン。
- 数字カード：ラベル（英字・大文字）の下に数字（タイトルサイズ）。横に並べない。
- 見出し「分析」など英字の画面名は、左寄せ。

## 14. 共通部品（クラス名）
- 入力欄・選択欄 `.ui-input`（input と select の両方）：高さ48px、枠線（強い）、面 `#1f1f1f`、角丸6px、文字は本文サイズ。選択中は白い枠。
- ボタン `.ui-btn`：枠の白いボタン、高さ48px、英字の大文字（ラベルサイズ）。`.ui-btn-icon` は正方形（×など）。
- 読み込み中 `.ui-skeleton-list`：実際に出る行と同じ高さ（分析のトップは104px）・同じ左右の余白の帯が流れる。行数も実際の行数に合わせる。
- 「さらに表示」など一覧の下のボタンは `.ui-btn` を使い、横いっぱいにする。
- 曲名などの一覧（ポップアップ内）：行の内側に 14px / 18px の余白。枠線に文字が寄らないようにする。
- 表示の切り替えが5つ以上のとき：幅を均等（grid の列数で割る）。アイコンを上、短い日本語（2〜3文字）を下に置く。英字の長い名前は使わない。（プロフィールの HOME/MAP/SEARCH/CHEMISTRY/DISCOVER で確定）
- グループの切り替え（プロフィール上部）：G（グループ）だけを並べる。U（ユニット）は出さない。
- 分析へのリンク（プロフィール）：BE:FIRST のメンバーだけに出す。

## 15. 戻るボタン・変更ボタン（全画面で共通）
- 戻る（文字つき）`.ui-back`：高さ48px、枠なし、矢印（線）と「BACK」、下に細い線。
- 戻るは `.ui-back`（BACK つき）の1種類だけ。矢印だけの戻るは使わない（テストで検査）。
- 戻るは1画面に1つ。画面上部の BACK に `data-page-back` をつけ、`onclick="if(!universeInnerBack())…"` にする。中の画面に BACK（戻り先）があれば上の BACK がそれを押して1段だけ戻り、中の BACK は見せない（Styles.html）。重ねて出す画面の BACK は `data-keep-back` で残す。
- 変更など小さなボタン `.ui-btn.ui-btn-compact`：高さ40px。
- 写真は枠いっぱいに表示する。写真がないときは何も出さない（頭文字は出さない）。
- メンバーの名前とグループの間は 2px。
